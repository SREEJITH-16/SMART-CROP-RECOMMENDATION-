Pipeline 1 · Machine learning

Soil-based prediction

  1. User enters seven soil and environmental values
  2. Values are validated and ordered as {{ features|join(', ') }}
  3. MinMaxScaler, then StandardScaler
  4. {{ algorithm }} scores all {{ crop_count }} crop classes
  5. The three highest class probabilities are shown

Tamil Nadu regional profile

  1. User selects one of {{ district_count }} districts
  2. The district row is read from the {{ data_year }} dataset
  3. Agro-climatic zone and major soils are displayed as recorded
  4. Crops are sorted by cultivated area in hectares
  5. The ranking is labelled as a regional profile, never as a prediction

Limitations you should know about

Probability is not success
The percentage is the share of trees voting for a crop. It has not been calibrated or validated against real harvest outcomes.
The training data is synthetic in character
Each crop occupies a tight, well-separated band of values, which is why accuracy is so high. Real fields are messier, so field accuracy will be lower than the test figure.
No Tamil Nadu staples in the model
The model knows {{ crop_count }} crops. Groundnut, cholam, cumbu, ragi, sugarcane and gingelly are not among them, so it can never suggest them however suitable your conditions are.
The two features never combine
Selecting a district does not change the model's prediction, and your soil readings do not change the regional profile.
Cultivated area is history, not advice
The regional ranking reflects what was grown, shaped by irrigation, markets and policy — not what will grow best on a given field.
No rainfall in the regional dataset
District rainfall is not supplied, so it is shown as "Data not available" rather than filled in from another source.
Images are placeholders
Crop images are illustrations from the supplied asset pack, not photographs. They are labelled as such wherever they appear.

Planned, but not built

A combined mode taking district, soil type, NPK, pH, weather and irrigation together would need training data linking all of those to real outcomes. No such dataset was supplied here, so the mode does not exist. The code is organised to accept it later: the ML layer, regional layer, crop registry and image mapping are separate modules, and the district list is already exposed at /api/districts.
